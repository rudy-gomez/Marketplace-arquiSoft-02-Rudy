Proyecto académico que propone la arquitectura inicial de un **marketplace 
de productos para mascotas**, donde distintos *sellers* pueden ofrecer sus 
productos y los *clientes* realizar compras.

## 📖 Descripción
Marketplace desarrollado como caso de estudio para el curso de 
**Arquitectura de Software [IS-488]**. El proyecto abarca el análisis del 
sistema (actores, historias de usuario, requisitos, atributos de calidad, 
restricciones y drivers arquitectónicos) y una primera propuesta de 
arquitectura organizada en capas.
